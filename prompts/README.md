# Prompts

Ready-made prompts for AI agents, stored here so they do not run by themselves.

## How to use

1. Open the prompt file, for example
   [`create-game-autonomously.md`](create-game-autonomously.md).
2. Copy the text inside the code block (GitHub shows a copy button on it).
3. Paste it into a new chat with the AI.

## Prompts

- [`create-game-autonomously.md`](create-game-autonomously.md): the AI makes a
  complete game in its own folder `games/YYYYMMDDHHMM-game-name/` on
  `master` and adds it to the game list in the root README.

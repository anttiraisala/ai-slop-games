# Prompts

Ready-made prompts for AI agents, stored here so they do not run by themselves.

## How to use

1. Open the prompt file, for example [`make-a-game.md`](make-a-game.md).
2. Copy the text inside the code block (GitHub shows a copy button on it).
3. Paste it into a new chat with the AI.

## Prompts

- [`make-a-game.md`](make-a-game.md): the AI makes a complete game in its own
  folder `games/YYYYMMDDHHMM-game-name/` on its own branch.

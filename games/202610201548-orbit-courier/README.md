# Orbit Courier

Slingshot parcels past planets to the delivery station.

## How to play
- Blue planets pull your parcel in, pink planets push it away. Touching any planet destroys the parcel.
- Reach the golden delivery station to complete the level. Each level gives a limited number of parcels.
- Fewer parcels used means more stars (up to 3 per level). Finish all 8 levels to win.

## Controls
- Drag back from the green launch pad and release to fire (longer drag = more power). A short dotted preview shows the start of the path.
- `R`: restart the current level
- `Enter` / `Space` / click: continue on menus

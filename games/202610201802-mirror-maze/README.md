# Mirror Maze

A laser puzzle game: flip the mirrors so the beam lights up every target.

## How to play
- A red laser shoots from the source block. Light every green target to clear the level.
- Click a cyan mirror to flip it between `/` and `\`. Every flip is one move.
- Grey mirrors are fixed, purple prisms split the beam into two, walls block it.
- Try to finish in the par number of moves. 10 levels, progress is remembered in the browser.

## Controls
- Mouse click: flip a mirror
- `R`: restart level, `H`: hint, `N`: next level after clearing one
- Level buttons below the board jump to any level

## Notes
Levels were generated by a script and verified solvable by brute force; par is the true minimum number of flips.
